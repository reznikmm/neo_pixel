# NeoPixel LED Strip Demo

This folder contains a demonstration program showcasing the functionality
of controlling a NeoPixel LED strip using an STM32F4XX-M board. The program
demonstrates basic color and brightness control of the LEDs.

## Overview

The demonstration program is designed to work with the STM32F4XX-M development
board and a NeoPixel LED strip. It shows how to initialize and control
30 LEDs connected to pin PA1. The program will cycle through different colors
on the LEDs, demonstrating the capabilities of the NeoPixel library.

## Requirements

* STM32F4XX-M development board
* NeoPixel LED strip (12 LEDs)
* Development environment compatible with STM32F4 microcontrollers

## Setup

* Connect the NeoPixel LED strip to pin PA1 on the STM32F4XX-M board.
* Connect the STM32F4XX-M board to your development environment.

## Usage

Compile and upload the program to the STM32F4XX-M board. Upon successful
upload, the demonstration program will run, and the LEDs on the strip will
cycle through colors.

```shell
alr build
```
